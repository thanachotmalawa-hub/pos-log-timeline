# POS Log Timeline

เว็บรวม log ของเครื่อง POS ทุกตัวเป็นเส้นเวลาเดียว หาจุดผิดปกติ (log หาย, error, ข้อความแจ้งเตือน) จุด restart ผลคำนวณโปรโมชั่น และสรุปส่ง Dev
ไฟล์ log อ่านในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่ถูกส่งออกไปที่ไหน

## วิธีใช้

- เปิด `index.html` ได้เลย (ดับเบิลคลิก) หรือเปิดผ่าน GitHub Pages
- กด "เลือกโฟลเดอร์ log" / "เลือกไฟล์ / .zip" หรือลากไฟล์มาวาง
- ถ้าเปิดจากไฟล์ในเครื่อง บางเบราว์เซอร์ไม่ให้ลาก **โฟลเดอร์** มาวาง ให้ใช้ปุ่มเลือกโฟลเดอร์ หรือ zip ก่อนแล้วลาก .zip แทน

## โครงสร้างไฟล์

```
index.html              หน้าเว็บ (HTML อย่างเดียว) และลำดับการโหลดสคริปต์
css/style.css           หน้าตาทั้งหมด สีของโหมดสว่าง/มืดอยู่ที่ :root ด้านบนไฟล์
js/core.js              ตัววิเคราะห์ log ล้วน ๆ ไม่ยุ่งกับหน้าเว็บ (อ่านบรรทัด, หาช่วง log หาย,
                        จัดหัวข้ออาการ, แปลผลโปร PromoSrvMessage, ค่าตั้งต้นต่าง ๆ ใน Core.DEFAULTS)
js/app/state.js         ตัวแปรกลาง (st, S), การตั้งค่าที่จำในเบราว์เซอร์, ฟังก์ชันช่วย  ← โหลดก่อน
js/app/files.js         อ่านไฟล์ / โฟลเดอร์ / zip, ภาษาไทย TIS-620, ลากวาง, rebuild()
js/app/findings.js      การ์ด "จุดผิดปกติที่พบ", สรุปจำนวน, จัดการหัวข้ออาการ, ล้างข้อมูล
js/app/timeline.js      Timeline รวม: ตัวกรอง, ช่วงเวลา, แสดงบรรทัด, คัดลอกไป Excel
js/app/promotions.js    ผลคำนวณโปร: หาบิล/Common/เลขใบเสร็จ, หน้าต่าง XML/JSON, ตารางโปร
js/app/overview.js      กราฟ "ภาพรวมการเขียน log": ซูม, แถบภาพรวม, ช่วง log หาย
js/app/pull.js          แท็บ "ดึง log": สร้าง SQL (xp_cmdshell + PowerShell) ดึง log ตามห้องและช่วงเวลา
                        รายชื่อห้อง/โฟลเดอร์/ชื่อไฟล์อยู่ที่ PULL_ROOMS บนสุดของไฟล์
js/app/tabs.js          แท็บของหน้า (ภาพรวม & Timeline · จุดผิดปกติ · หัวข้ออาการ · ไฟล์ · ตั้งค่า)  ← ก่อน main.js
js/app/main.js          เริ่มทำงาน  ← โหลดสุดท้าย
data/sample-data.js     ข้อมูลตัวอย่างของปุ่ม "โหลดตัวอย่าง" (ลบหรือแทนด้วย [] ได้ถ้าไม่ต้องการ)
vendor/jszip.min.js     JSZip 3.10.1 (MIT) สำหรับอ่าน .zip โดยไม่ต้องต่อเน็ต
```

ไฟล์ใน `js/app/` ใช้ตัวแปรร่วมกัน (ไม่ใช่ module) ลำดับใน `index.html` จึงสำคัญ:
`state.js` ต้องมาก่อน, `tabs.js` ต่อจากไฟล์อื่นทั้งหมด และ `main.js` ต้องอยู่ท้ายสุด ไฟล์ที่เหลือสลับกันได้

## แก้อะไร ไปที่ไหน

| อยากแก้ | ไฟล์ |
|---|---|
| ข้อความ/ปุ่มบนหน้าเว็บ | `index.html` |
| สี ขนาด ระยะห่าง | `css/style.css` |
| กฎหาอาการ, หัวข้อ 0–13, ค่าตั้งต้น regex | `js/core.js` |
| รูปแบบเลขใบเสร็จ / Common ค่าตั้งต้น | `RCPT_DEFAULT` ใน `js/app/state.js` |
| จุดเริ่ม/จบบิลของผลโปร | `BILL_START`, `BILL_END`, `NEW_BILL` ใน `js/app/promotions.js` |

## ข้อมูลตัวอย่าง (data/sample-data.js)

ตัดมาจาก 3 เคสจริง (สาขา 17923, 08350, 19967) และลบข้อมูลส่วนบุคคลออกแล้วเพื่อเผยแพร่สาธารณะได้:
เบอร์โทร, ชื่อพนักงาน, Username ที่ใช้ Login และรหัส Session / อุปกรณ์ (แทนด้วย `00000000-0000-4000-8000-…`)
ไม่มีเลขบัตรประชาชน, IP หรืออีเมลในข้อมูลชุดนี้ ถ้าจะเปลี่ยนเคสตัวอย่าง ให้ลบข้อมูลเหล่านี้ก่อนทุกครั้ง
