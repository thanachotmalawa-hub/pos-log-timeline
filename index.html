POS Log Timeline

รวม log ทุกตัวเป็นเส้นเวลาเดียว หาจุดผิดปกติ (log หาย, error, ข้อความแจ้งเตือน) จุด restart และสรุปส่ง Dev ไฟล์ทั้งหมดอ่านในเครื่องคุณ ไม่ถูกส่งออกไปไหน
ล้างข้อมูลที่โหลดไว้? ไฟล์ log ทั้งหมดจะถูกเอาออกจากหน้านี้ (ไฟล์ในเครื่องไม่ถูกลบ)

ภาพรวมการเขียน log

แท่ง = จำนวนบรรทัด log (สูง = เขียนถี่) ช่วงที่ log หลักหาย (กดเพื่อซูมดู) Restart มี ERROR / FATAL ช่วงที่กำลังดู (แถบบนสุด)
วิธีใช้: คลิก บนกราฟ = เปิด Timeline ที่เวลานั้น · ลากซ้าย–ขวา = ซูมเฉพาะช่วงที่ลาก · คลิกแถบบนสุด = เลื่อนไปดูช่วงนั้น · ดับเบิลคลิก = ดูทั้งหมด

Timeline รวม

ช่วงเวลา ถึง
คลิกบรรทัดเพื่อดูข้อความเต็ม · ตัวหนา = บรรทัดสำคัญ · พื้นส้ม = คำที่ไฮไลต์ · แถบเขียว = restart · แถบแดง = error

ดึง log จากเครื่องสาขาผ่าน SQL

        เลือกห้องและช่วงเวลา → คัดลอก SQL ไปรันใน SSMS → เปิดโฟลเดอร์ที่ได้ในเว็บนี้
      

      
    
        
  1. เลือกห้อง log และช่วงเวลาด้านล่าง
    2. 
        
  2. กด คัดลอก SQL แล้ววางใน SSMS ที่ต่อเครื่องสาขาไว้ กด Execute (รันแบบทดสอบก่อน: แสดงรายการไฟล์ ไม่ copy)
    3. 
        
  3. รายการถูกต้อง → ติ๊ก "ทดสอบ" ออก คัดลอก SQL ใหม่แล้วรันอีกครั้ง ไฟล์จะไปอยู่ที่ C:\pull_log\<ชื่อเครื่อง>_<วันเวลา>\ ของเครื่องสาขา
    4. 
        
  4. เปิดโฟลเดอร์นั้นผ่าน \\IP\C$\pull_log แล้วลากเข้าเว็บ (แท็บแรก) จากนั้นลบโฟลเดอร์บนเครื่องสาขา
    5. 
      


      

        

          1. ห้อง log
          

            
            
            
          

          

        


        

        

          2. ช่วงเวลา (เวลาของเครื่องสาขา)
          

            
            
            
            
          

          

            ช่วงด่วน:
            
            
            
            
          

          

            
            
            
          

          

        


        

          3. ตัวเลือก
          
          
          log startup (logstartup, StartUpLog, DebugStartupLog) มักเขียนตอนเปิดเครื่องตอนเช้า จึงอาจไม่อยู่ในช่วงเวลาที่เลือก        

        

      


      


      

        

          
SQL สำหรับวางใน SSMS

          
        

        
      


      

        
หลังรันเสร็จ

        
เปิดโฟลเดอร์:\\<IP เครื่องสาขา>\C$\pull_log

        
ดูไฟล์ที่ดึงมา:EXEC master..xp_cmdshell 'dir C:\pull_log /s';

        
ลบเมื่อใช้เสร็จ:

        ใส่ชื่อโฟลเดอร์ที่ได้จากบรรทัด TO ตอนรันจริง คำสั่งจะลบเฉพาะโฟลเดอร์นั้นใน C:\pull_log
      

    

  


  

    

      

        
จุดผิดปกติที่พบ

        
      

      

      

    

  


  

    

      

        จัดการหัวข้ออาการและกลุ่มสาเหตุ
        
หัวข้อ 0–13 มีกฎในระบบอยู่แล้ว แก้ชื่อและกลุ่มได้ หัวข้อที่เพิ่มเองจะถูกเลือกเมื่อพบ "คำค้นใน log" ในช่วงก่อนค้าง (ใส่หลายคำคั่นด้วย | ได้) และใส่คำค้นเพิ่มให้หัวข้อเดิมก็ได้

        

          

            
#ชื่อหัวข้อกลุ่มสาเหตุคำค้นใน log (ไม่บังคับ)ค้นใน log

            
          

        

        

          
          
          
        

        

          
ใช้หัวข้อและการตั้งค่าชุดเดียวกันทั้งทีม: คนหนึ่งกด "คัดลอกการตั้งค่า" แล้วส่งให้เพื่อน อีกคนวางในช่องด้านล่างแล้วกด "นำเข้า"

        ชนิด log ตรวจจากเนื้อหาในไฟล์ก่อน ถ้าไม่เจอจึงใช้ชื่อโฟลเดอร์ เปลี่ยนเองได้ในช่อง "ชนิด"
